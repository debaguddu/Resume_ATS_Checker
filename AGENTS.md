# Antigravity Workspace Rules: Resume ATS Checker

## Mandatory Rule: Design Updates, README & WALKTHROUGH Synchronization
1. **Always Update README.md**: Any changes, additions, or modifications to the system design, architecture, module structure, database schema, or UI workflows MUST immediately be updated and documented in `README.md`.
2. **Always Update WALKTHROUGH.md**: Any newly introduced features, UI pages, user interaction workflows, exporter formats, or architectural changes MUST be documented and kept up to date in `WALKTHROUGH.md`.
3. **Architecture Completeness**:
   - The `README.md` must maintain an up-to-date **Complete Design Specification**.
   - Every individual module must have a clear description covering its purpose, functions, inputs, outputs, and dependencies.
   - Comprehensive **Flow Diagrams** (Mermaid diagrams) must be kept accurate and reflect the true end-to-end data and user workflows.
